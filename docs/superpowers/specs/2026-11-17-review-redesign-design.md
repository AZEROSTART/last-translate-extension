# 复习页重设计：把「结算」改成「回忆」

- 日期：2026-11-17
- 状态：设计（未实施）
- 范围：只重做侧栏复习视图（`src/panel/review.ts` + 对应 CSS）；不动 SRS 间隔表、学习库 schema、翻译链路、popup、快捷键
- 取代：`2026-11-12-review-reveal-after-grade-design.md` 的**交互顺序**（揭晓从「评级之后」移到「评级之前」），其余三条实质保留
- 修订：`2026-11-16-review-mnemonic-scene-design.md`（演出只在「没想起来」时发生，删「再看一次」）

---

## 0. 判断

**这一页现在不是复习，是一次带抽奖的结算：它把词和答案放在同一屏，用四个选项替你想，用三个数字让你算账，最后用一场 700 毫秒的动画庆祝一个你本来就认识的词。**

这一页是什么：

> **复习，是在词快要忘掉的那天，在没有任何选项的情况下把它想起来一次，然后诚实地说一句「我刚才想没想起来」。**

### 取舍：3 分钟清账，还是 10 分钟真正记住

**我选 3 分钟清账。** 理由四条，写在设计之前，因为后面每一个删除都由它决定。

1. **这一页的位置决定了它的时间预算。** 它在浏览器侧栏，用户正读到一篇文章的中途。这个位置给得起的是一次呼吸，不是一节课。承诺 10 分钟，用户不会做 10 分钟，他会关掉面板——然后这一页就再也不被打开。
2. **「真正记住」不发生在这一页。** 它发生在你读到那个词的那篇文章里，发生在这些词接下来两个月的每一次复习里。这一页唯一能做的是：保证每一次都是真的。把「记住」的活派给一页 UI，是拿糖霜当蛋糕。
3. **页面上的每一秒都是从回忆里偷的。** 四个选项、三个间隔数字、一段演出、一句「再看一次」、一次「下一张」——这些加起来的一分钟，本来可以用来把这个词再想一遍。
4. **它必须和翻译抢同一份注意力。** 翻译是这个产品的入口。复习页如果做成第二个学习产品，它就变成了入口旁边的收费站。

但「3 分钟」不是「草草了事」。这一版的验收口径是：

> **8 张卡，3 分钟内过完，而且每一张都真的先想过、后看过。**

所以砍掉的是**装饰和选择题**，不是**回忆**。回忆不但不砍，还要变成屏幕上唯一发生的事。

## 1. 现状解剖

### 1.1 从打开到下一张要几步

以用户刚发来的截图为准（`复习 (8)`、`measuring`、四选一）：

| # | 动作 | 点什么 | 在干什么 |
| --- | --- | --- | --- |
| 0 | 打开侧栏 → 点「复习 (8)」 | 1 次 | 进入 |
| 1 | 读词、读挖空句 | 0 次 | 词已经给出来了，句子语境几乎补全了空 |
| 2 | 从四个中文里挑一个 | 1 次 | **唯一被算作「作答」的一步** |
| 3 | 揭晓：释义 → 地鼠演出 → 画面钩子 → 再看一次 → 完整原句 | 0 次 | 读一屏新内容 |
| 4 | 点「下一张」 | 1 次 | 这时才写库 |

**每张 2 次点击；8 张 16 次点击，加上进入 1 次，共 17 次。**

自评卡（不进四选一的那 2/3）是 2~3 次：点一档 → 揭晓（同上）→ 点「下一张」；如果先点「想不起来，看答案」，再加一次。

### 1.2 每一步实际在干什么（代码为证）

**第一步就把答案说了一半。** `review.ts:601-617` 把 headword 渲染在卡片最上方，`review.ts:619-623` 在它下面渲染挖空句。用户看到的是「measuring」+「…the careful process of ____ before cutting.」——他不需要想起来，他只需要把两个已经摆在一起的东西对上。

**四选一不是提取，是认字。** `shared/spot.ts:47-70` 的干扰项按词库顺序取**最早收录的三个词**的释义（`for (const candidate of pool)`，`pool` 就是 `state.all.words`）。所以截图里 `measuring` 的三个干扰项是「妥协 / 最终一致性 / 比……存在得更久」——前两个跟挖空句毫无关系，「测量」是唯一讲得通的。这不是一道题，这是四个里挑一个眼熟的。同一批干扰项还会在整轮里反复出现，因为 `spotSeed()`（`review.ts:263-270`）只换顺序，不换集合。

**自评卡允许你不看答案。** `review.ts:497-507` 的揭晓按钮文案是「想不起来，看答案」——它把「我要确认一下」写成了「我认输了」。于是用户不点它，直接点「认识」（`review.ts:653-683`），答案在他已经评分之后才出现（`review.ts:386-389`）。这一页从头到尾没有一刻要求他读过答案。

**三档数字把复习变成了算账。** `review.ts:673-689` 在每个按钮上印出下次间隔，下面再写一行「数字是下次见到它的时间」。用户看到的是「认识 = 7 天后」，于是他的手指落在最划算的那一格，而不是最诚实的那一格。「模糊」尤其危险：它没有定义，它是给不敢承认的人准备的后门。

**揭晓那一屏，一半是糖霜。** `review.ts:497-548` 一次给出：主语言释义、其他语言释义并列、完整原句（用户刚看过、只多填了一个词）、演出舞台、画面钩子、「再看一次」。其中只有「释义」和「钩子」对记忆有用，而且两者服务的是两种不同的人：释义服务「想起来了」，钩子服务「没想起来」——现在它们被同时塞给所有人。

**装饰在同一张卡上出现了两次。** `review.ts:574-599` 的角落头像（`panel.css:440-448`，50×44）和 `review.ts:427-495` 的演出舞台是同一只地鼠。答案展开后头像被 `hidden`（`review.ts:595`），但它在提示屏上什么也不做。

### 1.3 蛋糕和糖霜

用户来这一页，只为了一件事：**确认自己还记得**。其余都是来了之后的点缀。

| 元素 | 它是什么 | 判定 |
| --- | --- | --- |
| 词 + 挖空语境句 | 唯一的材料 | 蛋糕 |
| 一次没有选项的回忆 | 发生在屏幕上、不在 DOM 里 | **蛋糕，现在缺失** |
| 「我刚才想没想起来」这一句 | 决定下次什么时候再见 | 蛋糕 |
| 下次再见的时间 | 调度的结果，机器的事 | 糖霜（现在是主菜） |
| 四选一 | 识别题，而且 headword 就在屏上 | 糖霜冒充蛋糕 |
| 地鼠演出 + 画面钩子 | 记忆锚点，但只在没想起来时才值钱 | 糖霜（应挪到失败时） |
| 再看一次 | 把记忆锚点变成玩具 | 糖霜 |
| 其他语言释义并列 | 极少用，多一行 | 糖霜 |
| 完整原句 | 用户刚看过 | 糖霜 |
| 答案语言下拉 | 一个设置项长在练习面上 | 糖霜 |
| 语言筛选 chips | 把一笔账拆成两笔 | 糖霜 |
| 已收录 16 个 | 积累的唯一证据 | 糖霜，但留（零成本，一天一行） |
| 有 5 天没见了 · 词都还在 | 唯一一句「东西没丢」 | 糖霜，但留 |
| 毕业行 | 唯一不可逆的好事 | 留 |
| 卡面角落头像 | 装饰，且与演出重复 | 砍 |

### 1.4 三个真问题

1. **它从来没问过那个问题。** 这一页问的是「这算几档」，不是「你想起来了吗」。缺的那块蛋糕就是问题本身。
2. **它把「确认」写成了「认输」。** 「想不起来，看答案」让用户不敢点，于是他们在没看答案的情况下评分。整个 v2 的「三档 + 后果可见」是在给这个不敢看的动作配解释。
3. **它奖励快，惩罚诚实。** 点「认识」永远比点「忘了」舒服，而系统没有任何一刻检验过。

## 2. 设计原则与砍掉的东西

### 2.1 五条原则

1. **一屏一个问题。** 屏幕上同时可点的东西超过一个，用户就在猜哪个是正事。提示态只有一个动作：看答案。
2. **先回忆，后确认；确认之前不给任何候选。** 任何出现在答案之前的选项，都把「回忆」偷换成「辨认」。
3. **机器记账，人只回答一件事：想没想起来。** 不问档位、不预览间隔、不解释算法。
4. **教学只在失败时发生。** 想起来了的那张卡不需要演出、不需要钩子、不需要第二遍；没想起来的那张才需要，也值得多花一次点击。
5. **诚实比舒服重要，所以不惩罚诚实。** 没有红色、没有默认档、没有「你退步了」。撤销是唯一的安全网，一次，够用。

### 2.2 据此砍掉的东西（12 条）

| # | 砍掉 | 为什么 |
| --- | --- | --- |
| 1 | 四选一（`renderSpot`、`.ilmt-review-options`、`buildSpotQuestion` 调用） | 干扰项与题面无关、headword 在屏，测的是认字 |
| 2 | 三档 → 两档（删 `hard` / 「模糊」） | 「模糊」没有定义；分不清就是没想起来 |
| 3 | 每个按钮上的下次间隔（`.ilmt-review-grade-due`） | 让用户在评级前算账 |
| 4 | 说明行「数字是下次见到它的时间」 | 解释一个不该出现在这里的概念 |
| 5 | 四选一的「记为认识 · 明天再见」（`.ilmt-review-next-note`） | 同上，且四选一已删 |
| 6 | 答案语言下拉（`.ilmt-review-gloss`） | 设置项回到设置页（`src/settings/sections/learning.ts` 已有） |
| 7 | 语言筛选 chips（`.ilmt-review-langs`） | 清账就是清账，不分科目 |
| 8 | 其他语言释义并列（`.ilmt-review-meaning-more`） | 确认只需要一个释义 |
| 9 | 完整原句（`.ilmt-review-sentence-full`） | 用户刚看过这句，只多填了一个词 |
| 10 | 卡面角落头像（`.ilmt-review-mascot`） | 角色只出现在它做事的时候 |
| 11 | 「再看一次」（`.ilmt-review-scene-replay`） | 演出播一次；重播按钮是逃避按钮 |
| 12 | 「已记录」前缀 | 回执要说的不是「写进去了」，是「你刚才那个词是什么」 |

同时删掉对应的样式与文案，不保留「以防万一」的隐藏分支。

## 3. 新页面

### 3.1 状态机（每张卡）

```
prompt ──点「看答案」──▶ revealed ──点「想起来了」──▶ 写库 ──▶ 下一张卡（prompt）+ 回执
                              │
                              └──点「没想起来」────▶ 写库 ──▶ lesson ──点「下一张」──▶ 下一张卡（prompt）+ 回执
```

- **写库只发生一次，发生在点档位的那一下。** revealed 之前没写，lesson 之后不再写。
- 「下一张」只存在于 lesson（没想起来之后），它只翻页，不写库。
- 想起来了这条路**没有「下一张」**——把 3 次点击压回 2 次，省下的那一次就是这一版最大的收益。

### 3.2 进入

不变：点顶部「复习 (8)」进入，第一张卡直接出现。没有开场、没有说明、没有「开始复习」按钮。

顶部chrome只剩一行，且都不是按钮：

```
已收录 16 个 · 已毕业 2 个
有 6 天没见了 · 16 个词都还在        ← 仅 gap ≥ 3 天且有到期时
```

（`renderShelf()`、`renderReturn()` 原样保留；`renderFilters()` 整个删除。）

### 3.3 提示（prompt）——这一屏是本轮重做的全部

```
┌──────────────────────────────────┐
│ 3 / 8                       结束 │   11px muted
│                                  │
│ measuring  n.                    │   24px/600 text 色（不是强调色）
│                                  │
│ A second paragraph describes the │   15px/1.65，左对齐
│ careful process of ____          │  ____ 渲染成一条浅色槽位
│ before cutting.                  │
│                                  │
│                                  │   空白：让句子是唯一内容
│ ┌──────────────────────────────┐ │
│ │            看答案            │ │   44px 实线主按钮，钉在卡片底部
│ └──────────────────────────────┘ │
└──────────────────────────────────┘
```

- 卡片里只有三样内容：词、词性、句子（顶部只留进度和出口）。**没有选项、没有档位、没有释义、没有头像。**
- 目标语言标签（`英语` / `西语`）只在**库内目标语言 ≥ 2 种**时显示（11px muted）；单一语言时不显示。
- 按钮文案从「想不起来，看答案」改成「看答案」：确认不是认输。
- 按钮固定在卡片底部（卡片 `min-height: 268px` + 动作区 `margin-top: auto`），8 张卡之间位置不移动——快速流里，手指不能每张卡重新找按钮。

### 3.4 揭晓与作答（revealed）

```
┌──────────────────────────────────┐
│ 3 / 8                       结束 │
│                                  │
│ measuring  n.                    │
│                                  │
│ A second paragraph describes the │
│ careful process of ____          │
│ before cutting.                  │
│                                  │
│ 测量                             │   17px/600，无底色块
│                                  │
│ ┌────────────┐ ┌────────────┐   │
│ │  想起来了  │ │  没想起来  │   │   两个按钮同样大小、同样颜色
│ └────────────┘ └────────────┘   │
└──────────────────────────────────┘
```

- 释义只有一个（`word.glossLang` 优先，回退 `glosses[0]`）；缺失时显示「释义还没生成」（muted），不阻塞评价。
- 两个按钮**视觉完全对等**：同样的 44px、同样的 1px 边、同样的文字色。没有红、没有青、没有默认高亮。这一屏没有「正确答案」，只有「你刚才记得吗」。
- 点任一按钮立即写库。写失败时停在原地，按钮保留可点，按钮下方出现 12px 的「没写进去 · 再点一次」。
- 句子保持挖空，不回填——词已经在上面了，回填就是同一句话说两遍。

### 3.5 没想起来（lesson）——教学唯一发生的地方

```
┌──────────────────────────────────┐
│ 3 / 8                       结束 │
│                                  │
│ measuring  n.                    │
│ A second paragraph ... ____ ...  │
│                                  │
│ 测量                             │
│ ┌────┐ 木匠眯眼拉长尺，把一段     │   演出 64×58 + 钩子字幕
│ └────┘ 木头量了三遍。            │
│                                  │
│ ┌──────────────────────────────┐ │
│ │            下一张            │ │
│ └──────────────────────────────┘ │
└──────────────────────────────────┘
```

- 词已经在点「没想起来」时写进库（`again` → box 0 → 10 分钟后），所以「下一张」**不写库**，只翻页。
- 演出与字幕复用 11-16 的实现（`renderScene`、`ensureScene`、`deps.mnemonic`），但**只在这条路径上请求和播放**。想起来的词不再请求模型——这会把画面生成从「每张一次」降到「只对错过的词」。
- 字幕加载中：「给它想一个画面…」；失败：「画面没生成出来 · 重试」（11px 文字按钮）。两者都不阻塞「下一张」。
- 不提供「再看一次」。演出播一次；字幕留在屏幕上，它才是锚点。
- 这一屏没有回执（释义已经在这里了），回执等翻页后再出现。

### 3.6 回执（翻页后）

```
┌──────────────────────────────────┐
│ measuring · 测量 · 7 天后再见  撤销│   12px，一条浅色分隔，无底色
└──────────────────────────────────┘
```

- 回执不是「已记录」，是**你刚才过的那张卡的答案**：词 · 释义 · 下次。想起来的那条路，用户唯一一次看到释义就是这里——所以它必须包含释义，这也是 11-12「点完评级看不到答案」的正式解法，用一行文字解决，不用一屏。
- 释义缺失时省略中间段：`measuring · 7 天后再见`。
- 已毕业：`measuring · 测量 · 已毕业`（不加「再见」）。
- 撤销仍是一次、仍只在 10 分钟内（`UNDO_WINDOW_MS`）。撤销后回到该词的 prompt 态，计数回滚，焦点回到卡片。

### 3.7 结束

四个分支，语气沿用 v3 的约定：不出现「坚持 / 连续 / 目标 / 别放弃」，不出现感叹号，不出现红色。

**C1 · 刚把这一轮做完（本轮有作答）**

```
┌──────────────────────────────────┐
│            8 个都过完了           │
│         3 个没想起来              │   ← 仅 M > 0 时
│                                  │
│  ┌──┐ measuring 毕业了            │   ← 仅本轮有毕业
│  └──┘                            │
│                                  │
│        今天已复习 12 个           │
└──────────────────────────────────┘
```

- 标题用**这一轮的数量**，不再用「今天没有要复习的词」——用户刚做完 8 个，这句话是在否认他刚才做的事。
- 只报「没想起来 M 个」。删掉「认识 M 个」：这个数字只能靠不诚实变大，而错过的数量才是下次要处理的东西。
- 不做「再过一遍」按钮：这些词 10 分钟后才到期，提前复习会破坏间隔。到点由徽标提醒。

**C2 · 打开就没有到期的词（本轮 0 作答）**：标题「今天没有要复习的词」，副行「明天还有 N 个」/「今天已复习 N 个」，与现在一致。

**B · 中途点「结束」且还有到期**：「本轮先到这 / 还有 N 个到期 / 今天已复习 N 个 / [继续复习]」——原样保留。

**A · 一个词都没有**：「还没有收录的词」+ 一段引导 + 「翻译当前页：⌥A」——原样保留。

### 3.8 空状态与异常

| 情况 | 表现 |
| --- | --- |
| 库里 0 个词 | A 页，不渲染 shelf / return / 毕业块（现状） |
| 今天没有到期 | C2 页（现状） |
| 词没有语境句 | **不渲染句子行**，卡片只剩词 + 词性 + 按钮（现状会渲染出一行孤零零的 `____`，见 `review.ts:255-260`） |
| 释义缺失 | 「释义还没生成」，可正常评价 |
| 写库失败 | 留在 revealed，两档可点，出现「没写进去 · 再点一次」 |
| 画面生成失败 | lesson 里显示重试文字链，不影响翻页 |
| 撤销太晚 / 不支持 | 沿用现有三种终态文案（`review.ts:1096-1103`） |

## 5. 最该先做的三件事

**第一件：把四选一和「答案在屏上」一起拿掉。**
提示屏只剩词 + 挖空句 + 「看答案」。这一步做完，这一页第一次真的要求用户想起来。代码改动集中在 `renderCard` / `renderAnswer`，删 `renderSpot` 与 `spot.ts` 调用。

**第二件：三档变两档，写库点从「下一张」挪到档位本身。**
揭晓后两个等权按钮，点下去就写、就翻页；只有「没想起来」留下来看演出。这一步把 3 次点击变成 2 次，也把「诚实」变成最省力的一条路。

**第三件：把揭晓那一屏剩下的糖霜全部删掉。**
其他语言、完整原句、再看一次、答案语言、语言 chips、角落头像、间隔文案。删完以后再调字号与对齐——先做减法，布局会自己变简单。

三件都集中在 `src/panel/review.ts` 与 `src/styles/panel.css` 里，按顺序做，每一步都能单独跑测试。

## 7. 边界

### 7.1 非目标

- 不改 `INTERVALS_MS`、`applyGrade`、box 语义、`MAX_BOX`。
- 不改 `LearningWord` / `LearningState` schema，不加字段，不升 `version`。
- 不改 `review-answer` / `review-undo` 消息结构。
- 不改翻译、悬停卡、popup、快捷键、徽标、设置页。
- 不做反向卡、拼写题、语音、图片、连续天数、热力图、统计页、成就。
- 不引入暗黑模式（现有 `prefers-color-scheme` 分支保持原样）。
- 不新增依赖、权限、推送。
- 不做键盘快捷键（留给第二阶段，见 §9）。

### 7.2 对 P0 的影响

| P0 项 | 影响 |
| --- | --- |
| 快捷键 ⌥A / ⌥Q / ⌥S | 无 |
| 翻译与恢复 10/10 | 无 |
| popup provider/model | 无 |
| 复习写库 | **时序变化，语义不变**：每张卡仍恰好一次 `review-answer`，写库点从「下一张」变成「点档位」；`applyGrade` / 撤销快照 / `stats` 口径不动。E2E 需改两行点击顺序，断言（box 前移、dueAt、徽标清零、撤销回滚）全部保留 |

### 7.3 数据兼容

- 旧记录里的 `grade: "hard"`、`spot`、`spotCorrect` 继续可解析（`parseReviews` 不改），只是不再产生；UI 不展示。
- `checksSinceSpot` 仍按 `input.spot ? 0 : +1` 递增（background 不改），无实际用途，无害。
- 已有 `mnemonic` 继续复用；没有 `mnemonic` 的词只会在「没想起来」时生成。
- `sessionStorage` 的 `ilmt:review-lang` / `ilmt:review-gloss-lang` 不再读写；旧值留在当前标签页里，随关闭消失，无迁移。
- 不做批量修数据、不回写、不重算 box。

### 7.4 无障碍

- 两个档位是原生 `<button>`，文字即标签，不依赖颜色区分（红/青已删）。
- 释义区 `aria-live="polite"`，翻页后读屏播报「测量」。
- 回执 `role="status"` + `aria-live="polite"`，播报「measuring · 测量 · 明天再见」。
- 挖空用 `<span class="ilmt-review-blank" role="img" aria-label="空">`，读屏读「空」，不读四个下划线。
- 进度 `3 / 8` 是纯文本；「结束」是按钮，可 Tab 到达。
- 翻页后焦点落在「看答案」；撤销后落在卡片容器（既有行为）。
- 演出舞台 `aria-hidden="true"`，信息由字幕承担；`prefers-reduced-motion: reduce` 时 `animations: false`（沿用 `renderScene` 现状）。
- 所有触控目标 ≥ 44px。

### 7.5 性能

- 每张卡的 DOM 节点显著减少（少 4~6 个按钮、2 段文字）；`render()` 仍是一次全量重建，成本更低。
- 画面生成从「每次揭晓都请求」降到「只对错过的词请求一次」：想得起来的词整条路径不产生模型调用。
- 无新增网络、定时器、存储监听；不引入虚拟化（一次只渲染一张卡）。
- `formatDueLabel` 仍是纯函数，`render()` 内不产生额外 IO。

## 10. 已知风险

1. **测试改动量大于代码改动量。** `panel-review.test.ts` 有 50+ 用例、1368 行，本设计删 3 组、重写 1 组。这是第一阶段真正的工作量，也是唯一可能拖过一轮的地方。缓解：按 §6 的 U1–U17 逐条替换，不保留兼容分支。
2. **自觉报告仍然可以被滥用。** 想起来了/没想起来仍然是自报。这一版把「看答案」变成必经一步、把写库变成一次点击，作弊成本比现在高；真正的解法是第二阶段的停留时长。
3. **少了一次点击 = 少了一次反悔。** 现在有「改判」，新版没有；安全网只剩撤销一次。如果用户误点，10 分钟内可回。接受这个代价。
4. **3 分钟的目标没有自动化断言。** 只能用「每张 2 次点击」和人工抽查记录时间。如果实测 8 张仍要 6 分钟，说明句子太长或释义太晚出现，先砍句子的显示长度，不要加动画。
5. **词没有语境句时卡片会空。** 复习页只修「不渲染空句子」，不修「收录时为什么没有句子」——那是悬停卡与收录链路的活，属于下一轮。
