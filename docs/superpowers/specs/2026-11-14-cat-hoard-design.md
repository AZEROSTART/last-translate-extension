# 收录特效：怀里猫（cat-hoard）设计

- 日期：2026-11-14
- 状态：已实现（2026-11-14）
- 相关：`2026-11-13-claim-effects-design.md`（特效契约）
- 素材：用户提供的一张英短金渐层照片（懒、半眯眼、肉脸）。**不抠图**，按神态重画成内联 SVG。

## 1. 意图

第二个收录特效，让轮换不至于每次都是地鼠。用户的原话是「用这个猫咪重塑一个特效」，
看到「真照片抠图没法换色、没法做动作」之后选择**重新画**。

角色性格来自照片：懒得理你、微愠、但还是管了。所以动作不是「吃掉词」，而是
**伸爪把词扒拉进怀里藏着**——正面又克制，且「藏」和「收录进学习库」在语义上对得上。

## 2. 目标

1. 新增 `cat-hoard` 特效，与 `gopher-hole` 并列进入注册表，随机轮换、设置页勾选/固定/试一试三条链路自动生效。
2. 神态可辨认：宽圆脸、两耳朝外、半眯吊梢眼、小口鼻、向右甩的尾巴、蜷起的身体。
3. 动效：悬停时猫趴着、尾巴慢扫；点击后爪子上抬 → 词块从词下方飞进猫怀 → 猫收爪、闭眼、身体轻压；`settled` 定格为「抱着词装睡」；`known` 睁开一只眼瞥一下。
4. 深色模式换毛色变量；`animations=false` 时直接落到终态（与地鼠一致）。
5. 契约不变：点击只触发一次 `ctx.claim()`，幂等、失败回滚、`aria-label` 统一文案、`destroy` 清定时器。

## 3. 非目标

- 不使用位图素材，不引入 `web_accessible_resources`、不改 manifest。
- 不做多帧精灵、不做音效、不做点击以外的交互。
- 不改 `ClaimEffect` 契约与卡片布局逻辑（只新增一个 `reserve` 数值）。

## 4. 方案取舍

| 方案 | 说明 | 结论 |
| --- | --- | --- |
| A. 照片抠图 | 真毛发质感最好 | 否：无透明通道素材、深色模式无法调色、动作只能是整体位移 |
| B. 照片描摹成 SVG（选定） | 保留神态，共用 CSS 变量与深色模式，可做分部件动画 | 是：与地鼠同一套体系，体积小、无外部资源 |
| C. 纯贴纸式的二次元猫 | 好画、但丢掉照片的性格 | 否：用户要的是「这只猫」 |

分工：按 B 做，`gopher-hole` 不动，只加注册与导入。

## 5. 造型规格（视觉基线）

- viewBox `0 0 64 60`，渲染 `64 × 56`，`reserve.below` 从 48 调到 60。
- 毛色：`--ilmt-cat-fur` / `--ilmt-cat-fur-2`（背脊略深）/ `--ilmt-cat-belly`（下巴与胸口）/ 深色模式整体调亮一档。
- 头部占画面约 60%：椭圆宽脸 + 两个外撇的小耳朵（耳内粉色）。
- 眼睛：上眼睑压住一半瞳孔的「半眯」形，瞳孔是暖琥珀色；`known` 时只画一只睁眼。
- 口鼻：小三角鼻 + 一个很浅的「人」字嘴，嘴角向下一点点（不爽）。
- 身体：左侧蜷起的梨形，胸口与尾巴分开画，尾巴末端向右上翘。
- 词块：`12 × 8` 的圆角小纸片，两条灰线代表文字，飞入后藏在两爪之间。

## 6. 时序

| 阶段 | 时长 | 画面 |
| --- | --- | --- |
| `idle` | 循环 4.2s | 尾巴扫动，身体轻微呼吸；不动时眼睛半眯 |
| `hit` | 720ms | 0–18% 爪子上抬、头微抬；18–52% 词块从词下方弧线飞入怀里；52–78% 双爪合拢、身体下压 1.5px、闭眼；78–100% 定格 |
| `settled` | 定格 | 抱着词块、闭眼、右侧浮出 `+1 已收录` |
| `known` | 定格 | 词块仍在怀里，一只眼睁开，不写库、不显示 `+1` |

动效关闭时：点击后立刻进入 `settled`/`known`，不播放 keyframes。

## 7. 实现落点

- `src/content/effects/cat-hoard.ts`：SVG 构造 + CSS + `mount`，`registerEffect`。
- `src/content/glossary.ts`、`src/panel/review.ts`、`src/settings/sections/learning.ts`：各加一行 `import "./effects/cat-hoard"`（复习卡头像自动跟着走）。
- `docs/previews/cat-effect.html`：四态 × 明暗的静态预览页，作为后续改动的视觉基线。
- 单测 `tests/unit/cat-hoard.test.ts`：镜像地鼠的契约用例（只收一次、known、失败回滚、动效关闭、`setState`、按钮文案、重复点击、词块唯一性、层级顺序）。
- E2E `tests/e2e/settings.spec.ts`：固定 `cat-hoard` 后「试一试」能挂载且点击不写库。

## 8. 留给实现者的判断

- 猫的具体线条与比例以 `docs/previews/cat-effect.html` 截图为准，允许在 64px 下简化细节（胡须、趾缝可以省略）。
- 词块是否在 `known` 阶段出现：留实现判断，默认出现（表示词已在库里）。
- 复习卡 50×44 的容器装 64×56 的猫会略微溢出，允许 `transform: scale(.86)` 收进原位，不改复习卡布局。
